# 수상한 초대장 — PIXEL GAME / Vite + React

## 실행

1. 이 폴더에서 `npm install`
2. `npm run dev`
3. 배포 파일 만들기: `npm run build` (결과: dist)

## StackBlitz의 기존 Vite + React 프로젝트에 넣기

- src 폴더 안의 모든 파일을 같은 위치에 복사합니다 (PixelArt.jsx 포함).
- public/pixel 폴더도 반드시 복사합니다. 도트 그림과 한글 픽셀 글꼴이 들어 있습니다.
- src/main.jsx도 제공 파일로 교체하면 기본 Vite index.css 스타일이 섞이지 않습니다.
- index.html을 교체하면 제목도 '수상한 초대장'으로 바뀝니다.
- 별도 UI 라이브러리나 API 키, 백엔드는 필요 없습니다.
- TypeScript 템플릿 대신 React JavaScript 템플릿을 사용하면 그대로 적용됩니다.

## 내용 수정

src/content.js에 이름, 생년월일, 장점, 사진, 질문/정답, 선물 문구가 모여 있습니다.

- recipient: 비우면 방문자가 입력한 이름을 사용합니다.
- birthday: 비우면 유효한 과거/오늘 날짜는 모두 통과합니다. 특정 수신인을 확인하려면 YYYY-MM-DD를 입력합니다.
- birthday는 오늘 날짜와 비교하는 기능이 아니라 입력된 생년월일과의 일치 확인입니다. 이벤트 연출상 입력 확인 후 항상 생일 축하가 나옵니다.
- questions[].answer: 첫 보기=0, 둘째=1, 셋째=2, 넷째=3.
- 사진 파일을 public/photos에 넣고 src를 '/photos/photo1.jpg'처럼 지정하세요.
- 모든 내용을 채운 뒤 demo: false로 바꾸면 예시 안내가 사라집니다.
- 입력은 메모리에서만 사용합니다. 새로고침하면 진행이 초기화됩니다.
- 실제 인증 기능은 아닙니다. 정답, 생년월일 등 소스에 넣은 내용은 방문자가 확인할 수 있습니다.
- 한글 픽셀 폰트 Galmuri11을 포함했습니다. 폰트 라이선스는 public/pixel/FONT-LICENSE.txt에 있습니다. 외부 폰트 요청이 없습니다.
- 효과음은 기본 OFF. 오른쪽 위 SOUND 버튼으로 켜면 Web Audio API로 짧은 게임 효과음이 재생됩니다. 오디오 파일이나 API 키가 필요 없습니다.
- 도트 캐릭터와 배경은 SVG/CSS로 구현했습니다. 디자인 시안 이미지의 상세 숲 그림과 완전히 동일한 이미지는 아닙니다.
- 모바일 레이아웃, 키보드 포커스, 모션 감소 설정을 지원합니다.
- React와 Vite 외에 별도 npm 패키지가 필요 없습니다.

## 화면 순서

초대장 → 정보 입력 → 생일 축하 → 장점·함께한 순간들 → 선물 수령 의사 → 퀴즈와 애정 질문 → 선물 공개
수취 거부, 선물 거절, 애정 질문의 '아니요'는 재질문 창을 엽니다. 닫기/Esc도 가능합니다.
